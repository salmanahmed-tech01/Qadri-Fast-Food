# Qadri's Food Mountain website

Files
- index.html: all four pages (Home, Menu, About Us, Visit Us) in one file, switched by the #home, #menu, #about and #visit links
- style.css: colours, layout, animations and responsive rules
- script.js: page switching, menu tabs, Instagram button and the 3D hero cards

How to edit
1. Instagram: open script.js and paste the profile link into INSTAGRAM_URL at the top.
2. Menu: open script.js and edit the MENU object. Each group has a name (g), an optional note (n) and a list of item names (i). Names only, no prices.
3. Colours: change the variables at the top of style.css (:root).
4. Phone, address and links: search index.html for 0314 1114864 or 923141114864 and update them.

Open index.html in a browser to preview. No build step is needed.
